# GODDESS 創世の書(Ver.5)

世界を創った女神アステリアになって、人族と魔族の歴史を裏からあやつるゲームです。
世界の地図をながめ、気になった国・人物・軍・町を選び、神託・夢・噂・奇跡・災害などで介入します。
時間を進めると、人物と国が自分の考えで動き、その結果が地図とニュースで見えます。
決まったエンディングはありません。何百年でも歴史が続きます。

---

## 1. 起動方法

### いちばん簡単
`dist/goddess-sousei.html` をダブルクリックして、ブラウザで開くだけです。
画像もすべて中に入っているので、このファイル1つで遊べます。スマホでも遊べます。

### 開発用(ファイルを分けたまま動かす)
画像を読むために、かんたんなサーバーが必要です。

```
cd goddess6
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765/index.html` を開きます。

### 1つのHTMLにまとめ直す
```
python3 tools/build.py
```
`dist/goddess-sousei.html`(そのまま遊べる版)と `dist/goddess-sousei-artifact.html`(公開用)ができます。

## 2. 遊び方(基本の流れ)

1. **世界を見る**: 下の「いま注目の出来事」に、いちばん大事な出来事が最大3つ出ます。番号は地図の印と同じです。
2. **選ぶ**: 地図の国・町・軍・戦場、一覧の人物、注目の出来事を押すと、右にくわしい情報が出ます。
   人物なら「いま考えていること(目標・これからしそうなこと)」「人間関係」「記憶」がわかります。
3. **介入する**: 右の「女神の介入」から力を選びます。内容(例: 勝利の夢 / 破滅の夢)、相手、強さ(弱く・ふつう・強く)、タイミング(今すぐ・来月・次の季節)を組み合わせます。
4. **時間を進める**: 上の ▶(ふつう)/ ▶▶ / ▶▶▶ で進みます。スペースキーでも止める・進めるができます。
5. **結果を見る**: 軍が動き、町が包囲され、国境の色が変わります。ニュースと注目の出来事に結果が出ます。

- 大きな出来事が起きると、カメラがその場所へ移り、時間が止まります(メニューで切りかえられます)。
- 大きな会戦では「戦場を見る」を押すと、横から見た戦場の画面で、加護・天候・啓示・星を落とす・英雄の覚醒が使えます。
- 人物や国を選んで「長期計画を立てる」を押すと、「侵攻を決断させる」「王位につかせる」などの計画を始められます。左の「計画」タブで進み具合とおすすめの介入が見られます。
- 住民は女神の正体を知りません。ゲームの中で正体がばれることもありません。知っているのはプレイヤーだけです。

## 4. 新しい設計(どう動いているか)

```
毎日 … 軍の行軍・補給、敵軍との会戦、町の包囲、予約した介入
毎月 … 町の暮らし(人口・不満・信仰)、国の判断(宣戦・和平・同盟・神殿)、事件の発生、信仰→神力
毎年 … 人物が年をとる・病気・死・結婚・子どもの誕生
```

- **人物の判断**: 君主が攻めこみたい気持ちは、野心・性格・国境の緊張・相手国への感情・兵力の差・復讐の記憶・相手の君主との友情・戦争の疲れ・女神の介入(夢や神託)を足し合わせて決まります。だから同じ介入でも、相手の性格で結果が変わります。
- **事件**: 「きっかけ → 関わる人物 → 人物の選択と出来事 → 結果 → 次の事件」の形で記録されます。
  例: 国境の衝突 → 戦争 → 会戦で敵将を見のがす(恩義が生まれる)/ 首都が落ちる → 王の死 → 王位継承争い → 内乱で国が2つに割れる
- **くり返し防止**: 同じ種類・同じ人物・同じ場所の事件には待ち時間(クールダウン)があります。2回目以降の国境衝突は「◯度目」と記録され、緊張がより高まります。文章も人物の性格や状況で変わります。
- **信仰**: 人族と魔族の信仰を別々に計算します。戦争・包囲・疫病のときほど祈りが増えます。平和になっても、神殿と文化があれば信仰はゼロになりません。
- **歴史が毎回ちがう**: 世界の種(シード)で、大陸の形・国・人物・歴史が変わります。

## 6. 実装済みの機能と、まだの機能

### 実装済み(動作確認ずみ)
- 世界マップ(真上から見る)。国の色の領土、国境、戦争中の国境は赤。ドラッグ・ホイール・ピンチでズーム
- 人族の国3つ・魔族の国3つで始まり、内乱・反乱・再興で国が増えたり減ったりする
- 町(人口・城壁・守備兵・信仰・神殿・民の不満・疫病・飢饉・焼けあと)
- 人物(性格2つ・能力・野心・信仰心・恐れ・自信・名声・人間関係・記憶・家族・うらみ)と「いま考えていること/これからしそうなこと」の表示
- 軍(名前・国・指揮官・兵の数・編成・士気・補給・位置・目的地)。地図の上を実際に移動する
- 会戦(援軍が加わる、指揮官の戦死、英雄の活躍、退却)、包囲(城壁がくずれる、救援、陥落)、占領で領土の色が変わる
- 重要な戦いの戦場画面(兵が並んで戦い、倒れる。女神の力で戦いが変わる)
- 国の判断: 宣戦・和平(休戦期間)・同盟・同盟の解消・神殿の建設・軍の編成
- 事件: 国境の衝突、戦争、和平、同盟、王位継承争い、新王朝、内乱(国の分裂)、暗殺/暗殺未遂、クーデター、裏切り、反乱(元の国へもどる・解放・自由都市)、滅んだ国の再興、英雄の誕生、敵将への情け、虐殺、疫病、飢饉、祭り、宗派の対立、種族をこえた出会い、亡命者の願い、王家の結婚、子どもの誕生
- 事件の連鎖(「きっかけ」と「ここから生まれた出来事」をたどれる)とくり返し防止
- いま注目の出来事(最大3件。何が・なぜ・誰が・これから)と、地図上の番号の印
- 大きな出来事でのカメラ移動と一時停止(メニューで切りかえ)
- 女神の介入 29種類(間接: 神託・夢・野心・恐怖・自信・出会わせる・不信・噂・関係悪化・関係改善・反乱のきっかけ・信仰を広める・士気・道に迷わせる・啓示 / 直接: 英雄の力・寿命・病・加護・豊穣・疫病・軍事力・技術・治癒・地震・結界・嵐・星を落とす・奇跡の光)。強さ3段階 × タイミング3つ × 内容・相手の組み合わせ
- 地図の場所を選んで奇跡や災害を起こす
- 戦場での力 5種類(加護・天候・啓示・星を落とす・英雄の覚醒)
- 長期計画 7種類(侵攻を決断させる・和平を壊す・戦争を終わらせる・王位につかせる・英雄に育てる・国を分裂させる・2人を結びつける)。進み具合・期限・おすすめの介入・成功/失敗
- 人族と魔族の信仰を別々に管理、信仰から神力
- 時間の停止・3段階の速さ、セーブ/ロード(ブラウザに保存・ファイルに書き出し/読みこみ)、毎年の自動セーブ
- はじめての人向けの説明(6ステップ)、スマホの画面(地図を全面、情報は下から出る)
- BGMと効果音

### まだできていないこと・簡単にしたこと
- **地域(レベル2)の専用画面はない**。ズームすると町の名前と兵の数が出る、という形で切りかえています
- **宗教施設は町の一部**として表示しています(神殿だけを選ぶことはできません)
- **顔の絵は使い回し**です(同じ顔の別人がいます)。人物の数だけ絵を作るのは難しいため
- **経済はかんたん**です(お金や食料の細かい数字は画面に出していません)
- **海の上は通れません**(船・海戦はありません)
- **声はありません**(人物が毎回ちがうので、前の版のような声つきセリフはありません)
- 人物の文章は、性格や状況で変わる文の組み合わせで作っています。AIがその場で文章を書くわけではありません
- 長く遊ぶと、小さな国(町1つ)がたくさんできて、また滅びる時代が来ることがあります
- ネットにつながっていないと、見出しの字体(明朝体)がふつうの字体になります

## 7. 動作テストの結果

### 画面のテスト(`tests/ui-play.js`、完成版HTMLを実際に操作)
PC(1440×860)とスマホ(390×844)の両方で、すべて ○ でした。
- 注目の出来事カードを押すと詳細が出る / 地図をタップして選べる
- 介入 11種類(人物・国・町・軍・場所・予約)と、設定画面からの介入(結果画面が出る)
- 長期計画を立てられる / 時間が進む(2年分)/ 60fps で動く
- 戦場画面で女神の力を使うと、戦いの記録に残る
- セーブ・ロードで元にもどる / JavaScript のエラーなし

### 介入は歴史を変えるか(`tests/influence.js`)
同じ世界を2つ用意し、片方だけ君主に「勝利の夢」「戦えという神託」「自信」と国境の衝突を与えました。
- 2年以内にその2国が戦争になった割合: **何もしない 2/12 → 介入 8/12**
- 介入しても戦争にならなかった4つは、ほかの国と戦争中だったなど、国の事情で君主が動かなかったケースです(人物は自分の意思で判断します)

## 8. 今後の改善案

1. **地域画面(レベル2)**: 町を押したとき、その地方だけを大きく見せる画面と、町の人々の様子
2. **女神の手帳の強化**: 自分の介入が、どの事件につながったかを線でたどれる「因果の地図」
3. **人物の顔を増やす**: ChatGPT / Google Flow で、年齢・種族・役職ごとの顔を追加
4. **英雄と魔王の物語**: 英雄の旅、一騎打ち、伝説として語りつがれる人物
5. **海と船**: 海をこえた侵攻、港町の交易
6. **文化と技術の時代**: 何百年たつと、武器や町の見た目が変わる
7. **歴史の本**: 300年の歴史を、年表と物語の本の形で読める画面(YouTube の動画にも使える)
8. **調整**: 長く遊んだときに小さな国が増えすぎないよう、反乱と再興のバランスをさらに調整
