# GODDESS

女神と世界の運命を描くシミュレーションゲーム。ブラウザでそのまま遊べます。

**▶ 遊ぶ: https://planet-vs-planet.github.io/goddess/**

## バージョン

| バージョン | 内容 |
|---|---|
| [v4 運命の書](https://planet-vs-planet.github.io/goddess/v4/) | 最新版。場面ごとに「運命の書」を書き換えて世界の結末を決める |
| [v3.3 三戦線](https://planet-vs-planet.github.io/goddess/v3_3/) | 北部・中央・南部の三戦線をリアルタイムで見守る戦線版 |
| [v1 大陸地図版](https://planet-vs-planet.github.io/goddess/v1/) | 最初の版。大陸地図の上で国家と人々の歴史が自動で紡がれる |

## 補足

- 元コード一式（テキストまとめ）に含まれていなかった自動生成ファイル（音声データ voices.js 等）は空で代用しています（音声なしで動作します）。
- 一部の画像（ユニットの立ち絵・城・部隊スプライト等）は元一式に含まれていなかったため表示されませんが、ゲームの進行には影響しません。
- v1 は Phaser 3（CDN配布物を同梱）を使用しています。
